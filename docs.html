Snapshot query demo

This browser demo queries the submitted movie dataset using the original search parameters and response format. The original course project uses FastAPI, PostgreSQL, Docker, and a refresh pipeline. This GitHub Pages version uses a fixed snapshot and performs queries in your browser; it does not host a FastAPI server or PostgreSQL database. The endpoint examples below describe the original project and can be tried through the browser adapter.

Endpoints

  • GET /health — snapshot availability and movie count
  • GET /genres — valid genre names
  • GET /movies — filtered and paginated results
  • GET /movies/{movie_id} — one movie
  • GET /summary/genres — weighted genre summaries
  • GET /summary/directors — weighted director summaries

Search parameters

genre: required, exact genre name. min_average_rating: 0–5. min_rating_count: nonnegative integer. sort: rating or popularity. limit: 1–100. offset: nonnegative integer. format: json or csv.

Filters and ordering use unrounded rating averages. Responses round averages to three decimals. Movies without ratings do not pass the average-rating filter. CSV download follows the requested limit and offset.
